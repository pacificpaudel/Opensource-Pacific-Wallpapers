# pacificwallpapers

## AI photo location

The photo details at the bottom of the new tab page include an AI location lookup. Add an OpenRouter API key in Wallpaper Settings to enable it. The extension sends the current wallpaper image URL to OpenRouter automatically; results are cached locally for up to 50 images. The API key is stored in this browser's local extension storage and is not synced.

AI location results are estimates based on recognizable landmarks or geography. The lookup reports when it cannot identify a place confidently.
